# court-form — เอกสารยื่นศาลตามแบบพิมพ์ศาลยุติธรรม (PDF)

สคริปต์ไฟล์เดียว รับไฟล์ข้อมูล JSON แล้ววาดแบบพิมพ์ศาลใหม่ทั้งฉบับเป็น PDF พร้อมพิมพ์ยื่น
ออกไฟล์ Word (.docx) ควบคู่ได้ด้วย สำหรับแก้ไขต่อ

สคริปต์วาดแบบพิมพ์ขึ้นใหม่ตามแบบพิมพ์ของศาล ไม่ได้กรอกลงไฟล์ของศาล จึงไม่มีข้อมูลคดีเก่าติดมา
ผลลัพธ์ทุกฉบับต้องผ่านการตรวจทานของผู้ใช้ก่อนนำไปยื่นหรือใช้จริง

## ใช้งาน

```bash
curl -fsSL https://raw.githubusercontent.com/Amataykul/court-form/main/court_form.py -o court_form.py
python3 court_form.py --list                       # แบบที่รองรับ
python3 court_form.py spec.json out.pdf            # สร้าง PDF
python3 court_form.py spec.json out.pdf --docx     # สร้าง PDF และ out.docx ควบคู่
```

ต้องมี Python, playwright และ Chromium (`pip install playwright && playwright install chromium`)
ฟอนต์ TH Sarabun สคริปต์ดึงจากแพ็กเกจ npm `@apw-pdf/fonts` (ฟอนต์แห่งชาติ SIPA) มาเก็บแคชไว้ที่
`~/.cache/court-form/fonts` ให้เอง หรือวางไฟล์ `THSarabunNew*.ttf` ไว้ที่ `assets/fonts` ข้างสคริปต์ก็ได้
ตราครุฑฝังอยู่ในตัวสคริปต์แล้ว

## แบบที่รองรับ

| `form` | แบบ | หน้าที่ได้ |
|---|---|---|
| `complaint` | (๔) คำฟ้อง | หน้า ๒ → ใบต่อ (๔๐ ก.) → ใบต่อรายละเอียดคู่ความ → (๕) หรือ (๖) คำขอท้ายคำฟ้อง → หลังแบบผู้เรียง/ผู้พิมพ์ |
| `request` | (๗) คำร้อง / คำแถลง / คำขอ | เลือกด้วย `kind` ตัวที่ไม่ใช้ถูกขีดฆ่าอัตโนมัติ |
| `answer` | (๑๑) คำให้การจำเลย | จำเลยหลายคนมีใบต่อรายละเอียดอัตโนมัติ |
| `appeal` · `appeal_reply` | (๓๒)+(๓๓) อุทธรณ์ · (๓๔)+(๓๕) คำแก้อุทธรณ์ | |
| `dika` · `dika_reply` | (๓๖)+(๓๗) ฎีกา · (๓๘)+(๓๙) คำแก้ฎีกา | |
| `proxy` | (๑๐) ใบมอบฉันทะ | หน้าเดียว |
| `witness_list` | (๑๕) บัญชีพยาน | ใบต่อ (๑๕ ทวิ) อัตโนมัติ |
| `lawyer_appointment` | ใบแต่งทนายความ (E-Filing) | `efiling: false` เพื่อซ่อนกรอบ |
| `property_list` | (๘) บัญชีทรัพย์ | ตารางราคา บาท/สตางค์ พร้อมแถวรวม |
| `witness_statement` | (๒๑ ทวิ) บันทึกถ้อยคำแทนการซักถามพยาน | ประวัติพยาน ๕ ข้อ + เนื้อความ |
| `settlement` | (๒๙) สัญญาประนีประนอมยอมความ | ท้ายเรื่องมีลงชื่อคู่ความและผู้พิพากษา |
| `bail_request` | (๕๗) คำร้องขอปล่อยชั่วคราว | ช่องทำเครื่องหมายชั้นพิจารณา ญาติผู้ติดต่อ EM + หน้าคำสั่งศาล |
| `bail_contract` | (๕๘) สัญญาประกัน | ข้อ ๑–๕ ตามแบบ + หน้าคำสั่งและรับทราบนัด |

แบบที่ยังไม่รองรับ (คดีผู้บริโภค แรงงาน ศาลปกครอง ภาษี ล้มละลาย เยาวชน อนุญาโตตุลาการ และแบบหมายของศาล)
ให้แจ้งผู้ใช้ว่ายังไม่มี อย่าดัดแบบอื่นมาใช้แทนโดยไม่บอก

**หน้าต่อ** — ตั้งแต่หน้า ๓ เป็นต้นไป ทุกแบบใช้แบบ (๔๐ ก.) ต่อเนื่องจนหมดหน้าสุดท้าย (หน้า ๒ เป็นหน้าสำนวนเปล่า ·
ใบต่อบัญชีพยานใช้ (๑๕ ทวิ) · คำขอท้ายฟ้องและท้ายอุทธรณ์ฎีกาใช้แบบของตัวเอง · หน้าคำสั่งศาลท้าย (๕๗)(๕๘) เป็นส่วนที่ศาลกรอก)

## ไฟล์ข้อมูล

คัดตัวอย่างในโฟลเดอร์ `examples/` ที่ตรงแบบมาแก้ (ข้อมูลในตัวอย่างสมมุติทั้งหมด ห้ามนำชื่อหรือที่อยู่ไปใช้)
คำอธิบายช่องข้อมูลทุกแบบอยู่ใน [`court-forms.md`](court-forms.md)

หลักที่ต้องถือทุกครั้ง

- ห้ามเติมชื่อ เลขคดี วันที่ เลขประจำตัว หรือจำนวนเงินเอง ช่องที่ยังไม่มีข้อมูลให้เว้นว่าง
- ชื่อ เลขใบอนุญาตทนายความ และที่อยู่ของทนาย ผู้เรียง ผู้พิมพ์ ต้องถามเจ้าของงานในงานนั้น
  ห้ามดึงจากงานก่อนหรือจากไฟล์ตัวอย่าง สคริปต์ปฏิเสธค่า `"default"` ทุกช่อง
- สคริปต์คืนค่า 2 พร้อมรายการคำเตือนเมื่อข้อความล้นช่องหรือคำขอท้ายฟ้องยาวเกินแบบ — แก้แล้วรันใหม่
  ห้ามส่งไฟล์ที่มีคำเตือนค้าง
- ตรวจไฟล์ก่อนส่ง: แปลงทุกหน้าเป็นภาพ (`pdftoppm -r 110 -png out.pdf p`) แล้วดูด้วยตาทุกหน้า · ตรวจฟอนต์ด้วย `pdffonts out.pdf` ต้องขึ้น THSarabunNew และ THSarabunNew-Bold ฝังในไฟล์

## การตัดบรรทัด

สคริปต์ตัดคำไทยด้วยพจนานุกรม ICU และจัดชิดขอบสองข้างโดยกระจายช่องไฟที่รอยต่อคำ
ชื่อคู่ความ เลขมาตรา จำนวนเงินกับหน่วย วันที่เต็ม และคำประสมกฎหมายใน `KEEP_WORDS` จะไม่ถูกตัดกลาง
คำที่ยังถูกตัดผิด ให้ครอบด้วย `[[…]]` ในงานนั้น และเพิ่มคำลง `assets/keep_words.txt`

## ไฟล์ Word

`--docx` ให้ไฟล์ **ร่างเนื้อความ** ตามรูปแบบเอกสารไทย (TH SarabunPSK 16 pt, A4, ขอบซ้าย ๓ ขวา ๒ บน ๒.๕ ล่าง ๒ ซม.,
ย่อหน้าแรก ๒.๕๔ ซม., ตั้งภาษาไทยให้ Word ตัดคำเอง) เปิดแก้ใน MS Office 2016 ได้
ไฟล์นี้**ไม่ใช่แบบพิมพ์ศาล** ไม่มีกรอบ ตราครุฑ ใบต่อ หรือการจัดบรรทัดลงเส้น ฉบับที่ยื่นศาลให้ใช้ PDF

## ที่มาของแบบ

วาดตามแบบพิมพ์ศาลยุติธรรมที่สำนักงานศาลยุติธรรมเผยแพร่ และใบแต่งทนายความแบบ E-Filing
ถ้าศาลประกาศแก้แบบ ต้องแก้สคริปต์ · ฟอนต์ TH Sarabun เป็นฟอนต์แห่งชาติ (SIPA) ใช้ได้เสรี
